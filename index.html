📋 О приложении

FlowPlan — умный планировщик с геймификацией. Помогает структурировать задачи, отслеживать прогресс и достигать целей.

🎮 RPG-система

  • Опыт (XP) — за выполненные задачи: 1 XP = 1 мин × 0.01
  • Уровень (LVL) — по формуле: N×(N+1)/2 XP для уровня N
  • Стрики — дни подряд с выполненными задачами
  • Эпические квесты — цели дают +1 XP

🏷️ Категории (Гильдии)

  • Тело 💪 — тренировки, подходы, вес
  • Творчество 🎨 — рисунки, тексты, музыка
  • Бизнес 💼 — проекты, контрагенты
  • Привычки 🔄 — формирование за 21 день
  • Одноразки 📌 — разовые задачи
  • Путешествия ✈️ — страны, бюджет
  • Долги 💰 — суммы, проценты
  • Питание 🥗 — калории, БЖУ
  • Другое 📂 — всё остальное

📊 Статистика

  • Тепловая карта активности
  • Прогресс-бары по категориям
  • Стрики общий и по гильдиям
  • История уровней
